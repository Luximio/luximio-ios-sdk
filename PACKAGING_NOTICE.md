# Development preview

This private repository contains the standalone Luximio iOS SDK, its synthetic
tests and build-only CI. There is no public release or version tag yet.

The selected customer composition is token recovery through
`TokenRecoverySession`. Earlier fixture, prototype and attested adapters remain
in the module; their presence is not a supported fallback. Both package products
use the same module and cumulative privacy resource.

Apache-2.0 covers Dot Square's original SDK code. See LICENSE, NOTICE and
[dependency notes](docs/dependencies.md). Service access, provider setup and
whole-app privacy declarations are separate from source access.
